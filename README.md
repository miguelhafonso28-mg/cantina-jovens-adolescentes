# 🍬 Cantina Jovens e Adolescentes

Site para montar pedidos, registrar na conta da pessoa e acompanhar quem já pagou.

## Acessar o site

👉 **[https://miguelhafonso28-mg.github.io/cantina-jovens-adolescentes/](https://miguelhafonso28-mg.github.io/cantina-jovens-adolescentes/)**

## Sobre

- Cardápio com doces, salgados e sorvetes
- Contas cadastradas, com atualização automática quando um pedido é registrado
- Gerenciamento de produtos e estoque
- Tema claro e escuro

Os dados ficam salvos no navegador (localStorage).
